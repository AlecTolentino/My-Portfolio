3D Arcade Machines Pack
Generated with polyy.ai

20 arcade machines in GLB format. Full-detail meshes straight from the generator.
Seven upright cabinets, a two-player fighting cabinet, a Japanese candy
cab, a light gun cabinet, an enclosed cockpit shooter, a ride-on
motorcycle machine, six sit-down racers, a dance machine and a bartop
mini. No text, logos or readable labels on any of them, so they fit
any fictional arcade.

Contents
  models/    GLB meshes, one file per machine
  previews/  animated turntable GIF for each machine, same filename
  LICENSE.txt

Engine notes
  Godot 4:   drag the .glb into the FileSystem dock and instance the scene.
  Unity:     GLB needs glTFast or UnityGLTF; both read these files directly.
  Unreal 5:  Import the .glb through the Content Browser.
  Blender:   File > Import > glTF 2.0.

Mesh details
  One mesh and one PBR material per file, with base colour and
  metallic/roughness textures embedded (PNG). No normal maps.
  Roughly 51,331 to 54,539 triangles per machine.
  Y-up. The origin sits at the centre of the bounding box, and each
  model is normalised to fit a box about 1 unit across, so set the
  scale to suit your scene and drop the pivot to the base.
